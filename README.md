# Taller 2 - Python Exercises

Proyecto educativo de ejercicios en Python organizados por temas, desarrollado como parte de un curso de programación en Python.

## 📋 Convenciones de Código

Este proyecto utiliza **camelCase** para nombres de variables y funciones, siguiendo estándares de nomenclatura consistentes a lo largo de todo el código.

## 🗂️ Estructura del Proyecto

### **Sección 1: Entrada y Salida Básica**
Introducción a los conceptos fundamentales de entrada y salida de datos en Python.

- **ejercicio1.1.py**: Confirmación de datos personales - Solicita nombre, edad y ciudad, validando la edad ingresada.
- **ejercicio1.2.py**: Calculadora básica - Realiza operaciones matemáticas (suma, resta, multiplicación y división) entre dos números.
- **ejercicio1.3.py**: Validación y manipulación de entrada de usuario.
- **ejercicio1.4.py**: Manejo de tipos de datos y conversiones.
- **ejercicio1.5.py**: Impresión formateada de información al usuario.

### **Sección 2: Estructuras de Control Básicas**
Ejercicios sobre condicionales y bifurcaciones.

- **ejercicio2.1.py** a **ejercicio2.5.py**: Práctica con sentencias `if`, `elif` y `else`.

### **Sección 3: Bucles y Iteraciones**
Dominio de estructuras repetitivas y control de flujo con `for` y `while`.

- **ejercicio3.1.py**: Números pares - Imprime todos los números pares desde 1 hasta N.
- **ejercicio3.2.py**: Sumadora continua - Suma números ingresados por el usuario hasta que ingrese 0.
- **ejercicio3.3.py**: Ejercicios con bucles anidados.
- **ejercicio3.4.py**: Control avanzado de iteraciones.
- **ejercicio3.5.py**: Secuencias numéricas y patrones.

### **Sección 4: Listas y Estructuras de Datos**
Trabajo con listas, diccionarios y búsqueda de información.

- **ejercicio4.1.py**: Comparación de listas - Encuentra elementos comunes y únicos entre dos listas.
- **ejercicio4.2.py**: Gestor de contactos - Sistema interactivo para agregar, buscar, eliminar y mostrar contactos usando diccionarios.
- **ejercicio4.3.py**: Manipulación de listas.
- **ejercicio4.4.py**: Búsqueda y filtrado de datos.
- **ejercicio4.5.py**: Operaciones avanzadas con estructuras de datos.

### **Sección 5: Funciones**
Definición y uso de funciones con parámetros y valores de retorno.

- **ejercicio5.1.py**: Generador de saludos personalizados - Función que devuelve saludos diferentes según la hora del día.
- **ejercicio5.2.py**: Cálculo de promedio - Función que calcula el promedio de una lista de números.
- **ejercicio5.3.py**: Funciones con múltiples parámetros.
- **ejercicio5.4.py**: Recursión y funciones avanzadas.
- **ejercicio5.5.py**: Funciones de utilidad general.

### **Sección 6: Proyecto Integrador**
Proyecto final que integra todos los conceptos aprendidos.

- **biblioteca.py**: Sistema de gestión de biblioteca - Aplicación completa con:
  - Registro de libros con ID autoincremental
  - Búsqueda por título o autor
  - Préstamo y devolución de libros
  - Estadísticas del sistema
  - Exportación de datos a archivo de texto
  - Menú interactivo

- Python 3.8 o superior
- Dependencias listadas en `requirements.txt`

Para ejecutar cualquier ejercicio:

```bash
python nombreDelArchivo.py
```

Por ejemplo:
```bash
python seccion\ 1/ejercicio1.1.py
python secccion\ 6/biblioteca.py
```
